# AiGENCY Demo Websites

Eleven self-contained portfolio demos based on the supplied 2026 build briefs. Social Supermarket is intentionally omitted from this collection as requested.

Each folder is a standalone static site: open its `index.html` directly or serve this directory with a local static server. The demos use seeded data and simulated AI operations; they require no API keys or backend services.

1. `02-charity-services`
2. `03-send-neuro-friendly`

9. `10-ai-transparency-scanner`

The common visual foundation lives in `shared.css` and `shared.js`; all app-specific behaviour remains in the relevant folder.
